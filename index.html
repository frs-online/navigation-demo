FRS-Online — statische Startseite-Demo

Identische, backend-freie Kopie der Startseite. Teste das Such-Panel (Lupe) und die Off-Canvas-Schublade / Mobile-Menü (Hamburger, rechte Slide-in-Sidebar mit Tabs + Kategorie-Akkordeon).

Gast-Ansicht
ausgeloggt — Login/Registrieren-CTAs, keine Preise Mitglieder-Ansicht (Endkunde)
eingeloggt — Preise, Konto-Popover, B2B-CTAs

Über einen lokalen Server öffnen: cd demo && python3 -m http.server 8000 → http://localhost:8000/. Details in README.md.
